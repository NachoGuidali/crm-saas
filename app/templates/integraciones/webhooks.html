Cómo se usa
  1. Cargá acá el sistema externo (URL + token).
  2. En Automatizaciones, creá una con la acción "Enviar datos a un sistema externo" y el disparador que quieras (ej. al entrar a "Datos completos").
  3. Cada envío lleva una URL de retorno (callback.url). Cuando el otro sistema termina, le hace POST con {"evento": "validacion_ok", "datos": {...}}.
  4. Otra automatización con el disparador "Cuando llega un evento externo" = validacion_ok mueve a "Validado", avisa, etc.
También con API key: POST {{ base }}/api/v1/eventos/ con {"telefono" u "oportunidad_id", "evento", "datos"}. Si en datos vienen claves iguales a campos personalizados, se guardan en la ficha.
